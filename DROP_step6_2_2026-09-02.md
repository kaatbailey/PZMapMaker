## Before building

```fish
cd ~/Documents/PZMapMaker

# 1. The line counts above.
wc -l groundregions.hpp groundregions.cpp groundregions_oracle.cpp \
      GroundRegionsOracle.java CMakeLists.txt VERIFY.md FINDINGS_F5_2026-09-01.md

# 2. The empty-file guard. A committed file has landed at 0 lines before,
#    and an empty ORACLE fails in the worst direction: a later session finds
#    no Java side, assumes it was never written, and rebuilds it differently.
find ~/Documents/PZMapMaker -maxdepth 1 -size 0 -not -path '*/.git/*'

# 3. Future mtimes. Ninja prints "Configuring done", then fails with
#    "manifest 'build.ninja' still dirty after 100 tries", builds NOTHING,
#    and leaves the old binary in place.
#
#    THIS MUST RUN AFTER EVERY COPY, INCLUDING THE ONE INTO THE JAVA TREE
#    BELOW. A file copied in afterwards arrives with its future stamp intact.
#    An extension glob is the wrong instrument -- it misses .java and cannot
#    reach the other repo. Use the catch-all:
find ~/Documents/PZMapMaker ~/Documents/PZMapCreation -not -path '*/.git/*' \
     -type f -newermt now -exec touch {} +

# Must print nothing:
find ~/Documents/PZMapMaker ~/Documents/PZMapCreation -not -path '*/.git/*' \
     -type f -newermt now

# 4. Delete the build dir rather than reconfiguring into it -- its build.ninja
#    has already recorded the future stamps.
rm -rf /tmp/noqt
```

**Ordering, corrected 2026-09-02:** copy everything first, into BOTH repos, then
touch, then remove the build directory, then configure. The first version of
this note put the touch before the copy and the drop failed exactly there.

**1. `Cover.WATER` has no branch in `build()`.** It falls through and becomes
ordinary ground — SAND, GRASS_MEDIUM or GRASS_DARK by distance — so a lake
enters the region array, dithers, and takes grass masks. WATER was added to the
enum on 2026-08-21, after that dispatch was written, and no branch came with it.
Measured, not argued: an all-NONE raster and an all-WATER raster produce
**identical 258x258 grids**, hash `3ca9cd66479d75a5`, 66,564 GRASS_DARK squares
each.

Ported as-is, because a port reproduces the Java. Mutation 21 in the FINDINGS
adds a WATER branch and diverges at 3 lines, so the oracle is watching this and
nobody can change it silently. **Whether it should have a branch is yours.**

**2. `YARD = 1`.** You said it looks like a guess and it is — STATE §28 and §29
both record `YARD = 3`, and the change to 1 is written down nowhere. Ported
verbatim; changing it is a behaviour change rather than a port and would break
the only oracle. It stays a named constant with its history in the doc comment.
If you want it measured, the check is vanilla `emptyoutside` room extents
against their host building footprints — `RoomCluster` already clusters rooms
into buildings and `emptyoutside` is 5,242 rooms across Muldraugh, so the
instrument mostly exists.
